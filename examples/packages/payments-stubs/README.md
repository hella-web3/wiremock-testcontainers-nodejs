# @examples/payments-stubs

A local npm package of WireMock stubs, installed into the examples project as a `file:`
dependency. It shows how teams share stubs between repositories: publish them as a package and
register its files with `{ package, file }` sources.

See [File sources](https://hellalabs.dev/docs/wiremock-testcontainers-nodejs/docs/guides/file-sources).
