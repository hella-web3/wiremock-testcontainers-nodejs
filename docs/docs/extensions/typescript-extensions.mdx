# TypeScript extensions

Register one object instead of JAR paths, class names and options – with typed helpers for the
stubs that use it. It only configures the container; nothing runs in Node.js.

## Implement the contract {/* #the-contract */}

`WireMockExtension`: `getName()` plus at least one other member.

| Member | Required | WireMock gets |
|--------|----------|---------------|
| `getName()` | Yes | Nothing – it identifies the extension; the same name twice must be configured alike |
| `getClassNames()` | One of these | Class names, merged into one `--extensions` |
| `getJars()` | ″ | JARs or directories – any [file source](../guides/file-sources.mdx) |
| `getOptions()` | ″ | Options, one per entry: `"--flag"` or `"--option=value"` |

## Register extensions {/* #registering-extensions */}

`withExtension()` takes an `ExtensionInput`: a class name, an extension object, or an
`ExtensionConstructor` – a class with a no-argument constructor, instantiated for you.
`withExtensions()` takes several, all or nothing.
