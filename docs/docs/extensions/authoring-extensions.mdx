## Locate JARs {/* #locating-jars */}

## Troubleshooting

```ts file=extensions/extensions.test.ts#errors
```

| Error contains | Fix |
|----------------|-----|
| `is not a fully qualified Java class name` | Include the package – not a short name, path or `.class` |
| `it contributes nothing` | Implement `getClassNames()`, `getJars()` or `getOptions()` |
| `must be "--flag" or "--option=value"` | One entry per option |
| `does not exist` | Locate the JAR with `{ module: import.meta.url, file }` |
| `must end in ".jar"` | Rename it: `{ file, name: "x.jar" }` |
| `did you mean …?` (on `start()`) | Fix the class name or register its JAR |
| `another extension named … is already registered` | One configuration per name |

WireMock's own errors: `ClassNotFoundException` – a missing class; `UnsupportedClassVersionError` –
a JAR built for Java newer than 11.

## Publish it

Ship extensions and JARs as an npm package: list the JARs in `"files"`, locate them with
`{ module: import.meta.url, file: "../jars/acme.jar" }`, and make
`@hellaweb3/wiremock-testcontainers-nodejs` a peer dependency.
