Every export, with its guide and a tested example. Full signatures: [API reference](../api/index.md).

## WiremockContainer

[`WiremockContainer`](../api/classes/WiremockContainer.md) – the builder. Also has every
[`GenericContainer`](https://node.testcontainers.org/features/containers/) method.

| API | Purpose | Guide | Example |
|-----|---------|-------|---------|

| [`withMapping(name, source)`](../api/classes/WiremockContainer.md#withmapping) | One mapping file or inline stub(s) | [Guide](../guides/registering-stubs.mdx#mapping-files) | [`stubs.ts`](https://github.com/hella-web3/wiremock-testcontainers-nodejs/blob/main/examples/stubs/stubs.ts) |
