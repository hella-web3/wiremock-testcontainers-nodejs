# Test isolation

Start one container per test file; reset it between tests – no restarts.

| Method | Stubs | Scenarios | Journal |
|--------|-------|-----------|---------|
| `reset()` | Registered ones only – runtime stubs dropped | Restarted | Emptied |
| `resetRequests()` | Kept | Kept | Emptied |
