# WireMock Testcontainers for Node.js

Run [WireMock](https://wiremock.org/) in [Testcontainers](https://node.testcontainers.org/) from
your Node.js tests, with a typed, fluent API.

New here? [Install](./getting-started/installation.mdx), then follow the
[quick start](./getting-started/quick-start.mdx).

## Find your task

| I want to… | Go to |
|------------|-------|
| Serve stubs from files, directories, npm packages or inline JSON | [Registering stubs](./guides/registering-stubs.mdx) |
| Point at a file by path, URL, module or package | [File sources](./guides/file-sources.mdx) |
| Pin the image or pass WireMock options | [Configuring the container](./guides/configuring-the-container.mdx) |
| Start, wait for, address or stop WireMock | [Container lifecycle](./guides/container-lifecycle.mdx) |
| Reset stubs, scenarios or the journal between tests | [Test isolation](./guides/test-isolation.mdx) |
| Assert what my code sent | [Verifying requests](./guides/verifying-requests.mdx) |
| Load a WireMock extension | [Java extensions](./extensions/java-extensions.mdx), [TypeScript extensions](./extensions/typescript-extensions.mdx) |
| Package an extension for my tests | [Authoring extensions](./extensions/authoring-extensions.mdx) |
| Run tests without Docker | [Running without Docker](./guides/running-without-docker.mdx) |
| Fix an error | [Troubleshooting](./reference/troubleshooting.mdx) |
| Look up an API | [API overview](./reference/api-overview.mdx), [API reference](./api/index.md) |
